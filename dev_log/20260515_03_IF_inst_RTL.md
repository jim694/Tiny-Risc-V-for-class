## 一、指令定义回顾

IF（Integrate-and-Fire）指令模拟脉冲神经网络的积分发放神经元，共享 opcode `0101111`（INST_SID），funct3=`010`。

| funct3 | 指令 | 功能 |
|--------|------|------|
| `000` | sID | 发送学号 |
| `001` | RT  | 读 LM75 温度 |
| `010` | **IF** | 积分发放神经元 |

**指令格式（I 型）：**

```
 31      20 19   15 14  12 11    7 6      0
┌──────────┬───────┬──────┬───────┬────────┐
│ imm[11:0]│  rs1  │ 010  │  rd   │0101111 │
└──────────┴───────┴──────┴───────┴────────┘
```

**两种工作模式：**

```
imm ≠ 0（积分）：x[rd] = x[rs1] + sign_ext(imm)
imm = 0（发放判断）：
    if x[rs1] >= x31（无符号）:
        UART 发送 x[rs1][7:0]
        x[rd] = 0
    else:
        x[rd] = x[rs1]
```

## 四、id.v

### 4.1 核心设计决策：x31 的读取

IF 是 I 型指令，编码中无 rs2 字段。发放判断模式需要与 x31（阈值 Vth）比较。解决方案：在 id.v 中对 IF 指令**硬连线** `reg2_raddr = 5'd31`，使 ex.v 的 `reg2_rdata_i` 始终为 x31。

```verilog
`FUNCT3_IF: begin
    reg_we_o     = `WriteEnable;
    reg_waddr_o  = rd;
    reg1_raddr_o = rs1;       // 膜电位 u
    reg2_raddr_o = 5'd31;     // 阈值 Vth（硬连线）
    op1_o        = reg1_rdata_i;
    op2_o        = {{20{inst_i[31]}}, inst_i[31:20]};  // sign_ext(imm)
end
```

此方案对其余流水线零侵入，不增加任何端口或总线访问。

## 五、ex.v

### 5.1 三路组合逻辑

在 INST_SID 的 case 分支内，按 funct3 进一步细分：

```
FUNCT3_IF
  ├── imm ≠ 0（积分模式）
  │     → hold=0, reg_wdata = rs1 + sign_ext(imm)   单周期无 stall
  ├── imm = 0, !if_active, !if_done, rs1 < x31（不发放）
  │     → hold=0, reg_we=1, reg_wdata = rs1          单周期无 stall
  └── imm = 0，其他（发放或状态机运行中）
        → hold=1, reg_we=0                            进入 stall
```

if_active / if_done 两个 case 外覆盖块处理状态机运行期和完成期：

```verilog
// 发放运行期：驱动 UART 写，if_wait_cnt==0 时写一次
if (if_active) begin
    hold_flag = `HoldEnable;
    if (if_wait_cnt == 13'h0)
        mem_waddr_o = 32'h3000_000C;  // UART TX 寄存器
        mem_wdata_o = {24'h0, if_byte};
end

// 发放完成：写 rd=0，释放 hold
if (if_done && opcode==`INST_SID && funct3==`FUNCT3_IF) begin
    hold_flag = `HoldDisable;
    reg_we    = `WriteEnable;
    reg_waddr = if_rd_addr;
    reg_wdata = `ZeroWord;
end
```

### 5.2 IF 时序状态机

| 阶段 | 条件 | 动作 |
|------|------|------|
| 触发 | imm=0, rs1≥x31, !if_active, !if_done | if_active=1，锁存 rd 和 if_byte=rs1[7:0] |
| 计数 | if_active=1 | if_wait_cnt 计数至 IF_N_WAIT（5000 cycles） |
| 完成 | if_wait_cnt==IF_N_WAIT | if_active=0, if_done=1 |
| 粘滞清零 | opcode 不再是 IF | if_done=0 |

`IF_N_WAIT = 5000` 与 sID 相同，在 115200 baud 下足够容纳 1 字节完整发送（≈4340 cycles）。

### 5.3 粘滞 if_done 机制

Hold_Freeze 期间 id_ex 冻结，opcode 仍为 INST_SID/FUNCT3_IF。若 if_done 在 opcode 未变化时就清零，状态机会重触发（与 sID/RT 存在同样的问题，解决方案也相同）：

```verilog
if (!(opcode == `INST_SID && funct3 == `FUNCT3_IF))
    if_done <= 1'b0;
```

## 六、流水线行为对比

| 路径 | 周期数 | hold | 寄存器写 |
|------|--------|------|---------|
| 积分（imm≠0） | 1 | 无 | rd = rs1 + imm |
| 不发放（rs1<x31） | 1 | 无 | rd = rs1 |
| 发放（rs1≥x31） | ~5001 | Hold_Freeze | rd = 0（完成时）|
