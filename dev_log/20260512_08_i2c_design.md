## 一、I2C 协议概述

### 1.1 物理层

I2C 使用两根**开漏（open-drain）**信号线，需外接上拉电阻至 VCC：

- **SCL**（Serial Clock Line）：主设备产生，控制传输节奏
- **SDA**（Serial Data Line）：双向，主从设备共享

开漏特性：任何设备都可以把线拉低，只有上拉电阻可以拉高。这是 ACK 机制（从机拉低第 9 个时钟）和多主机仲裁的硬件基础。

### 1.2 时序规则

```
SCL 高电平期间：SDA 禁止变化（数据采样窗口）
SCL 低电平期间：SDA 允许变化（数据切换窗口）

唯一例外：
  START：SCL 为高时，SDA 产生下降沿
  STOP ：SCL 为高时，SDA 产生上升沿
```

### 1.3 完整事务格式

**写事务（Master → Slave）：**
```
S  ADDR[6:0]  W(0)  A  DATA[7:0]  A  P
↑             ↑      ↑             ↑  ↑
START        主发  从ACK          从ACK  STOP
```

**读事务（Master ← Slave）：**
```
S  ADDR[6:0]  R(1)  A  DATA[7:0]  N  P
↑             ↑      ↑  从发       ↑  ↑
START        主发  从ACK        主NACK  STOP
```

- **ACK**：接收方在第 9 个 SCL 高电平期间拉低 SDA（0 = 确认）
- **NACK**：第 9 个 SCL 释放 SDA（1 = 不确认，用于读事务末尾）
- 数据在 SCL 上升沿采样，在 SCL 低电平期间切换，**MSB 先发**

### 1.4 速率与时钟分频

| 模式 | SCL 频率 | 50MHz 系统时钟分频系数 | 每半周期时钟数 |
|------|---------|---------------------|--------------|
| Standard | 100 kHz | 500 | 250 |
| Fast | 400 kHz | 125 | 62 |

本设计采用 Standard Mode（100 kHz），分频系数 500，每半周期 250 个系统时钟。

## 二、功能概述

实现一个 **I2C Master** 控制器，挂载在 RIB 总线 Slave 7（地址 `0x7xxx_xxxx`）。CPU 通过 MMIO 方式配置从机地址、写数据，触发事务，并读回接收数据。每次事务传输一字节（7 位寻址）。

---

## 三、寄存器映射

| 名称 | 总线地址 | addr[17:16] | 位宽 | 说明 |
|------|---------|-------------|------|------|
| CTRL | `0x7001_0000` | `2'b01` | 10-bit | 控制与状态寄存器 |
| WDATA | `0x7002_0000` | `2'b10` | 8-bit | 写数据寄存器 |
| RDATA | `0x7003_0000` | `2'b11` | 8-bit | 读数据寄存器（只读）|

### 3.1 CTRL 寄存器位域

| 位 | 名称 | 方向 | 说明 |
|----|------|------|------|
| [6:0] | ADDR | R/W | 7 位从机地址 |
| [7] | RW | R/W | 0 = 写事务，1 = 读事务 |
| [8] | START | W1S | 写 1 触发事务；事务完成后硬件自动清零 |
| [9] | BUSY | RO | 1 = 事务进行中；0 = 空闲 |
| [31:10] | — | — | 保留，读返回 0 |

**地址解码（addr[27:0]）：**

```
addr[17:16] = 2'b01 → CTRL
addr[17:16] = 2'b10 → WDATA
addr[17:16] = 2'b11 → RDATA
```

## 四、模块接口

```verilog
module i2c (
    input  wire        clk,
    input  wire        rst,

    // RIB Slave 7 总线接口
    input  wire [31:0] addr_i,
    input  wire [31:0] data_i,
    output reg  [31:0] data_o,
    input  wire        we_i,

    // I2C 引脚（开漏，片外上拉）
    output wire        io_scl,
    inout  wire        io_sda
);
```

SDA 使用 `inout` 三态接口：
- 驱动 0：`sda_out = 0, sda_oe = 1`
- 释放（高阻，上拉拉高）：`sda_oe = 0`

```verilog
assign io_sda = sda_oe ? sda_out : 1'bz;
wire   sda_in = io_sda;
```

SCL 为主设备独占，使用普通 `output wire`。

## 五、时钟分频

```verilog
localparam CLK_DIV = 250;  // 每半个 SCL 周期 = 250 个系统时钟

reg [7:0] clk_cnt;
reg       scl_r;           // SCL 寄存器值

always @(posedge clk) begin
    if (rst) begin
        clk_cnt <= 0;
        scl_r   <= 1;
    end else if (busy) begin
        if (clk_cnt == CLK_DIV - 1) begin
            clk_cnt <= 0;
            scl_r   <= ~scl_r;  // 每 250 拍翻转一次
        end else
            clk_cnt <= clk_cnt + 1;
    end else begin
        clk_cnt <= 0;
        scl_r   <= 1;           // 空闲时 SCL 保持高
    end
end

assign io_scl = scl_r;
```

事务过程中，在 SCL 上升沿前沿（`clk_cnt == CLK_DIV/2`）采样 SDA，在 SCL 下降沿后沿（`clk_cnt == 0`）切换 SDA。

## 六、状态机

### 6.1 状态定义（11 个状态）

```
IDLE      → 等待 START 触发
START1    → SCL=H，SDA: H→L（START 条件建立）
START2    → SCL: H→L（准备发送地址）
ADDR      → 逐 bit 发送 addr[6:0]+RW，共 8 bit
ADDR_ACK  → 释放 SDA，读第 9 个 SCL 的 ACK
WDATA     → 逐 bit 发送 wdata[7:0]，共 8 bit（写事务）
WACK      → 读写数据 ACK（写事务）
RDATA     → 释放 SDA，逐 bit 接收 8 bit（读事务）
RNACK     → 主机发送 NACK（SDA 保持高）
STOP1     → SCL: L→H，SDA 保持低
STOP2     → SDA: L→H（STOP 条件）→ 回 IDLE
```

### 6.2 状态转移图

```
                   START触发
IDLE ─────────────────────────→ START1
 ↑                                 ↓
 │                              START2
 │                                 ↓
 │                              ADDR（bit_cnt 0→7）
 │                                 ↓
 │                           ADDR_ACK
 │                            ↙       ↘
 │                    ACK=0              NACK（→ STOP1）
 │                 ↙        ↘
 │           RW=0             RW=1
 │           ↓                 ↓
 │         WDATA            RDATA（bit_cnt 0→7）
 │           ↓                 ↓
 │          WACK            RNACK
 │           ↓                 ↓
 └── STOP2 ← STOP1 ←──────────┘
```

### 6.3 关键时序（写事务，每 bit 500 个系统时钟）

```
        ←──────── 1 bit ────────→
SCL  ___________┌─────┐___________┌─────┐
SDA  ──── valid ──────── valid ────────────
          ↑切换SDA    ↑采样SDA
       SCL下降后    SCL上升后1/4周期
```

## 七、CPU 使用方式（MMIO）

### 7.1 写操作（CPU → 从机）

```asm
# 向从机地址 0x48 写数据 0xAB
li   t0, 0x70020000
li   t1, 0xAB
sw   t1, 0(t0)          # WDATA = 0xAB

li   t0, 0x70010000
li   t1, 0x148          # START=1, RW=0, ADDR=0x48
sw   t1, 0(t0)          # 触发写事务

poll:
lw   t2, 0(t0)
andi t2, t2, 0x200      # 检查 BUSY bit[9]
bnez t2, poll           # 等待事务完成
```

### 7.2 读操作（从机 → CPU）

```asm
# 从从机地址 0x48 读一字节
li   t0, 0x70010000
li   t1, 0x1C8          # START=1, RW=1, ADDR=0x48
sw   t1, 0(t0)          # 触发读事务

poll:
lw   t2, 0(t0)
andi t2, t2, 0x200
bnez t2, poll           # 等待事务完成

li   t0, 0x70030000
lw   t3, 0(t0)          # 读取结果 → t3[7:0]
```

### 7.3 等效 C 代码

```c
#define I2C_CTRL  (*(volatile uint32_t*)0x70010000)
#define I2C_WDATA (*(volatile uint32_t*)0x70020000)
#define I2C_RDATA (*(volatile uint32_t*)0x70030000)

void i2c_write(uint8_t addr, uint8_t data) {
    I2C_WDATA = data;
    I2C_CTRL  = (1<<8) | (0<<7) | addr;  // START, WRITE
    while (I2C_CTRL & (1<<9));            // 等待 BUSY=0
}

uint8_t i2c_read(uint8_t addr) {
    I2C_CTRL = (1<<8) | (1<<7) | addr;   // START, READ
    while (I2C_CTRL & (1<<9));
    return (uint8_t)I2C_RDATA;
}
```

## 八、RIB 总线集成

### 8.1 Slave 编号

```
Slave 0：ROM  (0x0xxx_xxxx) ← bridge
Slave 1：RAM  (0x1xxx_xxxx) ← bridge
Slave 3：UART (0x3xxx_xxxx)
Slave 6：PWM  (0x6xxx_xxxx)
Slave 7：I2C  (0x7xxx_xxxx) ← 新增
```

路由判断：`addr[31:28] == 4'b0111`（即 `== 7`）

### 8.2 需要修改的文件

| 文件 | 改动内容 |
|------|---------|
| `rtl/perips/i2c.v` | **新建**，实现 I2C master 模块 |

| `rtl/soc/tinyriscv_soc_top.v` | 新增 `io_scl`/`io_sda` 顶层端口，s7 wire，u_i2c 例化 |

### 8.3 顶层新增端口

```verilog

```

## 十、设计注意事项

### 10.1 SDA 三态

SDA 必须使用 `inout`，在 Vivado 综合时会推断为 IOBUF 原语。仿真时 `1'bz` 需要外部上拉（testbench 中 `pullup` 语句或 `assign io_sda = (sda_drive) ? 1'b0 : 1'b1`）。

### 10.2 ACK 超时

若从机不响应（SDA 未被拉低），状态机在 ACK 阶段采样到 NACK 后直接跳转至 STOP 状态，BUSY 清零，CPU 可通过再次读 CTRL 判断是否需要重试（可在未来添加 NACK 状态位）。

### 10.3 仿真验证限制

- 100kHz SCL 对应每 bit 500 个系统时钟，一次完整的 8bit + ACK 事务约需 4500 个系统时钟
- 标准 testbench 超时（25000 周期）足以容纳约 5 次完整事务
- 仿真需要一个简单的 I2C slave model（在 testbench 中实现 ACK 响应）

### 10.4 与温度传感器的对接

XDC 中 io_scl 已预留 M22、io_sda 已预留 N22，对应板上温度传感器接口。传感器典型地址和操作序列需参考器件 datasheet（如 LM75 地址为 0x48，读取方式为先写寄存器指针，再读温度值，需两次事务）。
