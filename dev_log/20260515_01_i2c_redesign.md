# I2C Master 重设计复盘：从半周期计数到 4 相自由时钟

**日期：** 2026-05-15  
**项目：** Tiny-Risc-V-for-class（RV32IM 三级流水线处理器核）

---

## 一、背景

RT 指令（通过 I2C 读取 LM75 温度传感器）上板验证时，UART 输出温度固定为 `0xFF`，排除了数据链路问题和地址错误后，定位到 I2C 通信本身存在问题。逐步修补原有 i2c.v 无法解决后，参照参考设计 `ref_temp_test/i2c_read_lm75.v` 从零重写了 I2C Master，验证通过。

本文复盘两版设计的本质区别。

## 二、原版设计（i2c_v1_halfperiod.v）

### 2.1 时钟结构

```
半周期计数器：half_cnt 从 0 计数到 CLK_DIV-1，复位归零
half 标志：0 = SCL 低半周期，1 = SCL 高半周期
```

状态机**直接产生** SCL：

```verilog
if (!half) begin
    scl_r <= 1'b1;   // 主动拉高 SCL
    half  <= 1'b1;
end else begin
    scl_r <= 1'b0;   // 主动拉低 SCL
    // 同一拍完成 SDA 切换
    sda_out_r <= next_bit;
    half <= 1'b0;
end
```

### 2.2 SDA 时序

- **SDA 改变时机**：与 SCL 下降沿**同一个时钟周期**（half=1 分支）
- **SDA 采样时机**：与 SCL 上升沿**同一个时钟周期**（half=0 分支）

```
时钟 N（posedge）: scl_r <= 0, sda_out_r <= new_bit   ← 同拍
时钟 N+1 ...: SCL 已为低，SDA 已为新值
时钟 N+CLK_DIV（posedge）: scl_r <= 1, shift_r <= sda_in  ← 同拍
```

**建立裕量 ≈ 0**（寄存器传播延迟决定实际裕量，典型 < 5ns）。

### 2.3 SDA 驱动

- `sda_out_r=0` → 驱动低（拉低 SDA）
- `sda_out_r=1` → 高阻（依赖外部/内部上拉拉高）

对于 SDA 需要为逻辑 '1' 的位（例如地址 0x48 的 bit7=1、R/W=1），信号能否到达 LM75 的 VIH 阈值完全取决于上拉电阻强度。

## 三、新版设计（i2c.v）

### 3.1 时钟结构

参照参考设计，采用**自由运行 4 相时钟**，与状态机解耦：

```verilog
localparam PHASE = 9'd50;  // 50MHz / 250kHz / 4 = 50 cycles/相

wire SCL_POS = (cnt_delay == 9'd0);     // SCL 即将上升
wire SCL_HIG = (cnt_delay == PHASE);    // SCL 已稳定高（采样点）
wire SCL_NEG = (cnt_delay == PHASE*2);  // SCL 即将下降
wire SCL_LOW = (cnt_delay == PHASE*3);  // SCL 已稳定低（改变点）
```

SCL 由独立 always 块生成，状态机**不控制 SCL**，只**响应**相位事件：

```verilog
always @(posedge clk) begin
    if (SCL_POS) scl_r <= 1'b1;
    else if (SCL_NEG) scl_r <= 1'b0;
end
```

### 3.2 SDA 时序

- **SDA 改变时机**：`SCL_LOW`（SCL 已稳定低 **50 cycles / 1μs** 后）
- **SDA 采样时机**：`SCL_HIG`（SCL 已稳定高 **50 cycles / 1μs** 后）

```
SCL_NEG（cnt=100）: scl_r <= 0          ← SCL 下降触发
cnt=101..149: SCL 已低，等待稳定
SCL_LOW（cnt=150）: sda_out_r <= new_bit ← SDA 改变，距下次 SCL 上升还有 50 cycles
cnt=151..199, 0: SCL 仍低
SCL_POS（cnt=0）: scl_r <= 1            ← SCL 上升
cnt=1..49: SCL 已高，等待稳定
SCL_HIG（cnt=50）: shift_r <= sda_in    ← SDA 采样，距 SCL 上升已 50 cycles
```

**建立裕量 = 50 cycles = 1μs**，满足 I2C Standard Mode（t_SU;DAT ≥ 250ns）和 Fast Mode（≥ 100ns）规范。

### 3.3 SDA 驱动

引入 `sda_link` 信号（同参考设计）：

```verilog
assign io_sda = sda_link ? sda_out_r : 1'bz;
```

- `sda_link=1, sda_out_r=1` → **推挽驱动高电平**（不依赖上拉）
- `sda_link=1, sda_out_r=0` → **推挽驱动低电平**
- `sda_link=0` → **高阻**（仅在从机需要驱动 SDA 的阶段：ADDR_ACK、WACK、RDATA1/2）

主机发送地址/数据时 SDA='1' 的位，由 FPGA 主动推挽驱动到 VDD，无需依赖上拉。

## 四、本质区别对比

| 维度 | 原版（半周期计数） | 新版（4 相自由时钟） |
|------|------------------|---------------------|
| **SCL 生成方式** | 状态机内主动拨 `scl_r` | 独立模块，状态机不介入 |
| **SDA 改变时机** | SCL 下降沿**同一拍** | SCL_LOW（稳定低后 1μs）|
| **SDA 采样时机** | SCL 上升沿**同一拍** | SCL_HIG（稳定高后 1μs）|
| **SDA='1' 驱动** | 高阻，依赖上拉 | 推挽，主动驱动 |
| **建立/保持裕量** | ~0（寄存器延迟）| 1μs（50 cycles）|
| **SCL 频率** | CLK_DIV 参数决定 | PHASE 参数决定（250kHz）|
| **状态机复杂度** | half=0/1 嵌套判断 | 扁平，每状态响应对应相位 |

## 五、故障排查过程回顾

```
输出 0x00（无 PULLUP）
  → 怀疑 I2C 未启动 / SDA 浮空偏低
  → 添加 XDC PULLUP true

输出 0xFF（有 PULLUP）
  → PULLUP 生效，SDA 空闲为高
  → 但 LM75 未驱动 SDA（NACK 或地址错误）

验证地址 0x48 正确（与参考设计一致）
  → 逐 bit 追踪地址帧：10010001 = 0x91 ✓

尝试推挽驱动（sda_link）
  → 输出仍为 0xFF
  → SDA 改变与 SCL 边沿同拍，建立裕量不足

参照参考设计重写（4 相时钟 + SCL_LOW 改变 SDA）
  → 上板验证通过 ✓
```

**根本原因**：原版 SDA 在 SCL 边沿同一时钟改变，建立裕量约为 0，LM75 在 SCL_HIG 采样时可能读到过渡值，导致地址识别失败（NACK），后续数据全为 SDA 空闲电平（0xFF）。

## 六、经验教训

1. **不要带入先验知识**：设计 I2C 时直接参考能工作的参考设计结构，而不是自行实现"通用 I2C"框架再逐步修补。

2. **SCL 与 SDA 时序必须解耦**：SDA 应在 SCL **稳定低期间**改变，在 SCL **稳定高期间**采样。自由运行 4 相时钟天然实现这一约束。

3. **推挽驱动消除上拉依赖**：主机发送阶段使用推挽而非开漏，避免上拉电阻强度成为隐性变量。

4. **0xFF 现象的诊断价值**：
   - 无上拉 → 0x00：SDA 浮空偏低（或事务未启动）
   - 有上拉 → 0xFF：事务启动但 LM75 未响应（NACK）
   - 两个现象组合缩小了排查范围
